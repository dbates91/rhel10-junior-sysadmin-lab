# Official Course 1 Master Framework

## Red Hat Junior Linux System Administrator Bootcamp

**Duration:** 12 weeks  
**Platform:** Red Hat Enterprise Linux 10  
**Alignment:** RH124 → RH134 → RHCSA EX200  
**Delivery:** video-supported instruction, guided labs, independent labs, troubleshooting tickets, interview drills, practical examinations, and GitHub documentation

## Mandatory Graduation Outcomes

### Track A — Junior Linux System Administrator Interview Readiness
Prepare for Junior Linux System Administrator, Junior System Administrator, Linux Support Administrator, Linux Infrastructure Support, and Systems Administrator I interviews.

Training includes conceptual explanation, troubleshooting scenarios, live demonstrations, 60–90 second technical answers, incident prioritization, escalation judgment, verification, GitHub walkthroughs, and behavioral/operational questions.

### Track B — RHCSA EX200 Examination Readiness
Prepare for the current RHEL 10 RHCSA EX200 performance-based examination. Every relevant lesson maps to the published objectives and includes independent practical tasks, verification, cumulative review, and persistence checks when applicable.

Both tracks run in parallel from Week 1.

## Curriculum

### Phase 1 — RH124: Weeks 1–5
- Week 1: Linux fundamentals, terminal navigation, filesystem hierarchy, commands, file management, links, and documentation
- Week 2: Vim, text editing, redirection, pipelines, searching, regular expressions, and file manipulation
- Week 3: Users, groups, passwords, permissions, ownership, sudo, and security policies
- Week 4: DNF/RPM, Flatpak, repositories, processes, systemd, and services
- Week 5: Networking, NetworkManager, TCP/IP, SSH, secure remote administration, RH124 practical assessment

### Phase 2 — RH134: Weeks 6–10
- Week 6: Bash scripting, conditionals, loops, archives, compression, secure file transfers
- Week 7: cron, at, systemd timers, logging, journald, time sync, process scheduling, performance tuning
- Week 8: GPT, swap, LVM, XFS/ext4/VFAT, persistent mounts, NFS, autofs
- Week 9: SELinux contexts, port labels, Booleans, firewalld, security troubleshooting
- Week 10: boot management, recovery, bootloader administration, RH134 review, practical assessment

Supporting topics such as RHEL installation, Kickstart, Podman, and image mode are included where useful but do not displace current EX200 objectives.

### Phase 3 — Weeks 11–12
- Week 11: comprehensive labs, production-style incidents, technical interviews, first full mock exam
- Week 12: capstone, additional RHCSA mock exams, troubleshooting evaluations, technical interview simulations

## Mandatory Lesson Sequence

1. Learning objectives
2. Video instruction
3. Instructor explanation
4. Guided lab
5. Independent lab
6. EX200 practical challenge
7. Junior SysAdmin troubleshooting ticket
8. Technical interview practice
9. Evaluation
10. GitHub documentation

Instruction is delivered interactively in manageable steps. Full solutions are not dumped before an attempt.

## Troubleshooting Framework

**Verify → Scope → Inspect → Isolate → Resolve → Validate → Document → Prevent**

## Weekly Schedule

- Monday: video, concepts, guided lab
- Tuesday: command repetition and guided practice
- Wednesday: independent lab and EX200 exercise
- Thursday: troubleshooting ticket and interview training
- Friday: cumulative review and practical assessment
- Weekend: capstone development, remediation, GitHub documentation, extra practical work

## Two-Server Lab

- Server 1: primary administration server/workstation
- Server 2: remote managed server introduced during networking for SSH, NFS, services, and troubleshooting

Use an isolated lab network and recovery snapshots/clones before high-risk exercises. Keep the footprint appropriate for the available laptop hardware.

## Continuous Capstone

**Enterprise RHEL Server Operations Lab**

The capstone evolves throughout the 12 weeks and accumulates filesystem administration, identities, permissions, sudo, SSH, networking, packages, services, Bash, scheduling, storage, LVM, NFS, SELinux, firewalling, logging, troubleshooting, backup/recovery exercises, and runbooks.

## Weekly Cumulative Assessment

Each practical combines new skills with earlier objectives. Previously learned skills reappear through spaced repetition.

## Internal RHCSA Readiness Standard

At least 85% on three consecutive comprehensive timed internal practical mock exams, with critical tasks completed and required persistent configuration surviving reboot.

## Final Assessments

### Examination A — Junior Linux System Administrator Technical Interview
20 technical questions, 5 troubleshooting scenarios, 2 live demonstrations, GitHub portfolio walkthrough, behavioral and operational questions.

### Examination B — RHCSA EX200 Practical Examination
Original timed performance tasks modeled on the current published objectives, requiring independent configuration, troubleshooting, validation, and persistence.
