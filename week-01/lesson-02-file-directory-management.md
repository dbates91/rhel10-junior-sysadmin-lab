# Week 1 Lesson 2 — Linux File and Directory Management

## Track Alignment

**RH124:** Managing Files from the Command Line  
**EX200:** Essential tools — create, delete, copy, and move files/directories  
**Interview:** explain file operations, path safety, and verification

## Lesson Outcomes

By the end of this lesson, independently:
- create files and directories
- copy files while preserving the source
- move files between directories
- rename files/directories
- remove files/directories safely
- verify the final filesystem state
- explain cp vs mv and safe deletion

## Training Sequence

Video → Instructor explanation → Guided lab → Independent lab → EX200 challenge → SysAdmin ticket → Interview questions → Evaluation → GitHub documentation.

## Administrative Habit

**Inspect → Change → Verify**

The full completed-lab write-up is added after the student performs and verifies the work.
