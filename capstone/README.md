# Enterprise RHEL Server Operations Lab

This is the continuous capstone for Course 1. It grows as each new administration domain is introduced.

## Current Stage — Week 1

Build foundational filesystem administration habits:
- navigate and inspect filesystem state
- create application directory structures
- create/copy/move/rename/delete files safely
- verify changes
- document completed work

Later weeks add identities, permissions, packages, systemd, networking, SSH, Bash, scheduling, storage/LVM, NFS, SELinux, firewalld, logging, troubleshooting, backup/recovery, and runbooks.

The final repository will explain architecture, operational decisions, validation, incidents, and administrative procedures.
