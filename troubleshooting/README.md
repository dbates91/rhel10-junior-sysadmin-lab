# Troubleshooting Notes

This directory will contain documented Linux break/fix incidents encountered during the course.

Each incident will use the following structure:

## Issue

What was reported?

## Impact

Who or what was affected?

## Evidence

What commands, logs, or observations were used?

## Root Cause

What actually caused the problem?

## Resolution

What change was made?

## Verification

How was the fix confirmed?

## Prevention / Follow-up

What could reduce the chance of the problem recurring?

As the course progresses, these notes will become increasingly similar to real junior system administrator ticket documentation.
